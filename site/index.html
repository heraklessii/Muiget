Muiget dosyayı parçalara bölüp paralel indirir, bağlantı koparsa kaldığı yerden devam eder. Açık kaynak, ücretsiz, telemetrisiz.

Windows için indir Kaynak kodu

Apache 2.0 · Windows x64 kurulumu 3,4 MB · Linux ve macOS henüz derlenmiş paket olarak sunulmuyor

Ne yapar

Bir indirme yöneticisinden beklenenler — fazlası değil, eksiği de değil.

Çoklu bağlantı

Dosya HTTP Range istekleriyle parçalara bölünüp (varsayılan 8) paralel indirilir. Tek bağlantıya göre belirgin hız artışı.

Kesintiye dayanıklı

Uygulama kapansa, bilgisayar çökse bile indirme kaldığı yerden devam eder. Yarım indirmeler açılışta listeye geri gelir.

Adaptif

Bir parça bitince en yavaş parçanın kalanı ikiye bölünüp devralınır. Hız sınırı ve saat bazlı kurallar da var — gece sınırsız, gündüz 2 MB/s.

Tarayıcı entegrasyonu

Chrome uzantısıyla sağ tık → “Muiget ile indir”, sayfadaki bağlantıları tarama ve isteğe bağlı olarak tarayıcı indirmelerini devralma.

Küçük

Tauri v2 + Rust. Kurulum paketi 3,4 MB, kurulu uygulama 14 MB. Electron tabanlı bir alternatif tipik olarak bunun on katından fazlasını kaplar.

Telemetri yok

Hiçbir veri toplanmaz, hiçbir sunucuya bir şey gönderilmez. Kodun tamamı okunabilir ve Apache 2.0 ile lisanslı.

Ne yapmaz

Bu net bir sınırdır ve değişmeyecektir.

  • Sitelerin indirme limitlerini, kotalarını veya hız sınırlarını aşmaz.
  • Rapidgator, Mega gibi premium link servislerinin kısıtlarını atlatmaz.
  • Bir sitenin kullanım şartlarını ihlal eden “bypass” özelliği içermez.

Buradaki “hızlı indirme” yalnızca meşru HTTP seviyesinde optimizasyon demektir: paralel Range istekleri, kaldığı yerden devam, bant genişliği yönetimi. Sunucu ne veriyorsa o indirilir.

Kurulum

Hazır paket için sürümler sayfasındaki .exe yeterli. Kaynaktan derlemek isteyenler için: 

# Rust 1.77+ ve Node.js 20+ gerekiyor
git clone https://github.com/heraklessii/Muiget.git
cd Muiget
npm install
npm run tauri dev    # geliştirme modu
npm run tauri build  # kurulum paketi üretir
